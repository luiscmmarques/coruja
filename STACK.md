# Stack

The technology choices and their reasons. The convention is inherited from Graftful, this project's sibling: same tools, same discipline, so anyone (or any agent) moving between the two repositories carries their knowledge with them. Divergences are listed at the end, each with its reason.

## Languages and framework

| Choice | Why |
| --- | --- |
| **TypeScript, strict** | The transfer round-trip discipline and the i18n catalogue both work by making mistakes fail to _compile_. Loose types would turn both into runtime surprises. |
| **Svelte 5 + SvelteKit** | Runes for reactivity, `adapter-static` for output that is only files. No server exists, so no framework server features are wanted. |
| **Plain CSS, custom properties** | The whole design system is a dozen tokens in `src/app.css`. A CSS framework would be larger than the app's own styles. |
| **System font stack** | No webfont: nothing to download, no invisible text on a slow connection, type that matches the phone it is on. Quicksand exists only as outlines inside the lockup files. |

## Data

| Choice | Why |
| --- | --- |
| **IndexedDB via Dexie** | The only runtime data dependency. Chosen for versioned migrations: hand-rolling `onupgradeneeded` chains across releases, on devices that skip versions, is a real source of data-loss bugs. |
| **Dexie `liveQuery` → Svelte stores** | One `live()` wrapper in `src/lib/db/index.ts`. Inert outside the browser, so prerendering cannot touch IndexedDB. |
| **JSON backup file** | The only copy of a shelf that exists outside one browser profile. `src/lib/domain/transfer.ts` validates structurally on import; `Required<T>` fixtures make the format acknowledge every model change at compile time. |

## PWA

| Choice | Why |
| --- | --- |
| **`@vite-pwa/sveltekit`, `injectManifest`** | The service worker is hand-written (`src/service-worker.ts`); the plugin only injects the precache list. Registered explicitly from the app — the plugin's auto-registration never reaches SvelteKit's prerendered HTML. |
| **Every route prerendered** | Each path gets its own shell with its own `<title>`, so link previews work and the worker has a real file to precache per route. |
| **`registerType: 'autoUpdate'`** | There is no update UI. Hashed asset filenames mean an old worker serves URLs that stop existing on deploy; prompt-and-wait would pin people to a broken version. |
| **CSP generated by SvelteKit, hash mode** | The inline bootstrap script changes every build; only generated hashes can allow it. `connect-src` pins the Open Library origins — the enforcement of "the ISBN is the only thing that leaves the device". |

## Scanning and lookup

| Choice | Why |
| --- | --- |
| **Native `BarcodeDetector` first** | Zero bytes shipped, best battery, on the platform a child's hand-me-down phone most likely runs (Chrome on Android). Feature-checked for `ean_13`, not just presence. |
| **`zxing-wasm` fallback, lazily imported** | Safari and Firefox have no detector. ~1 MB, fetched only on first scan on those browsers, served from our origin (the package's CDN default would break both the CSP and offline) and precached thereafter. |
| **Open Library, keyless, primary** | Run by the Internet Archive; mission-aligned with a no-tracking app. Used per its API guidelines: requests paced to the published 1/s, covers fetched by OLID to stay off the rate-limited ISBN path, everything cached after one fetch. |
| **Google Books, keyed, opt-in gap-filler** | Removed in v1 because its keyless quota is literally zero; returned in v1.1 with a referrer-restricted key baked in at build time (one per environment, DEPLOY.md). Asked only when Open Library falls short, and off by default in Setup — Google is not a non-profit, and the Privacy page treats that as a separate decision. |

## Quality gates

| Choice | Why |
| --- | --- |
| **Vitest, `node:assert/strict`** | The domain layer is the regression baseline and every mechanism carries tests. Assertions without framework matchers keep `src/lib/domain` import-free. Note vitest strips types without checking them — `svelte-check` is the type gate. |
| **Prettier + `svelte-check`** | The whole lint story. No ESLint: the type system and a formatter catch what matters here, and every added tool is a dependency someone must keep working. |
| **`prettier` with `proseWrap: 'never'`** | Prose — markdown and code comments alike — is one line per paragraph; editors soft-wrap. |
| **`headers.test.ts`** | The cache rules in `static/_headers` are load-bearing (a stale shell references deleted assets); the test makes adding a route without a cache decision fail. |

## Hosting

| Choice | Why |
| --- | --- |
| **Cloudflare Pages** | Static files at the edge, free tier, `_headers` support, serves `404.html` with a real 404 status. Build command `npm run build`, output `build/`, Node ≥ 22.6. |
| **No analytics script** | The CSP would block one anyway. Aggregate request counts from the host's edge are enough to know the app is used — see the Privacy page, which states this plainly. |

## Tooling for the identity

The mark's geometry lives once in `scripts/mark.mjs`; `build-marks.mjs` generates every icon SVG and asserts the geometry's claims (eye hole ≥ 2px at 32px render, inside the maskable safe circle). `outline-wordmark.py` (fontTools) converts Quicksand to outlines; `build-lockup.mjs` composes the lockup. Fonts are fetched to a gitignored `.fonts/` and never committed — only the outlines of six letters ship.

## Divergences from Graftful

| Divergence | Reason |
| --- | --- |
| **`zxing-wasm` as a second runtime dependency** | Graftful scans nothing. A book app that cannot scan on an iPhone is missing its core loop for half the family. |
| **Gamification exists** | Inverted deliberately, with the ten guardrails in `PLAN.md` replacing the blanket ban. Different audience, same care. |
| **One network egress instead of zero** | Auto-fill from an ISBN cannot be had for free. Disclosed, pinned by CSP, switchable off in Setup. |
| **Five launch languages, like Graftful** | Started with two; German, Italian and Portuguese (Portugal) joined before launch. The app is named in Portuguese, so pt was overdue. English defines the type; the other four are complete or the build fails. |
| **Mark geometry generated, not duplicated** | Graftful documents its mark's coordinates being copied across four files as a known trap. Here `scripts/mark.mjs` is the single source and the build asserts it. |
